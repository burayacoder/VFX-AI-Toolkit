# VFX-AI-Toolkit 🚀

Bu depo, profesyonel motion design iş akışlarını yerel yapay zeka ajanları ile otomatize etme projelerimi içerir.

## Projeler
* **Trend Analiz Motoru:** Güzellik merkezi sektörü için güncel TikTok/Reels trendlerini analiz eden Python ajanı.
* **VFX Otomasyonları:** After Effects iş akışlarını hızlandıracak script denemeleri.

## Teknik Altyapı
* **Beyin:** Ollama (Llama 3)
* **Arama:** Tavily API
* **Dil:** Python
